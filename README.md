## eBay为什么会盯上你的登录IP

eBay的风控系统持续记录每个账号的登录IP，几类情况会直接触发审查：多个账号从同一IP登录、IP属于数据中心或代理机房、同一IP段内频繁出现异常、登录IP与账号注册地址对不上。

机房IP是最容易被识别的类型。eBay维护着规模不小的IP黑名单库，常见云服务商和VPS厂商的IP段大多在里面，你在这些机器上登录后台，平台一眼就能认出机房流量。住宅IP由ISP直接分配给普通家庭用户，在平台眼里，登录它的就是一位住在洛杉矶的本地用户。

三种IP摆在一起，差别一目了然：

| IP类型 | eBay的判断 | 适合场景 |
| --- | --- | --- |
| 机房IP（数据中心） | 高危，大量IP段已被拉黑 | 普通建站、轻量代理 |
| 动态住宅IP | 中危，地址频繁切换反而可疑 | 爬数据、比价、短期任务 |
| 静态住宅IP（独享） | 与真实本地用户无异 | eBay多账号、店铺长期运营 |

**eBay用静态住宅IP还是动态住宅IP？**

建议一个。多账号共享一个IP，防关联等于零，出事是连坐封号。
